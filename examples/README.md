# Reference case index

Use these cases to calibrate scene analysis, environmental interaction, scale, occlusion, color separation, and quality review. They are reasoning references, not character templates.

- [Three-scene reference case](three-scene-case/README.md): alpine lake, modern skyline, and Hong Kong street; emphasizes varied scene design and documented limitations.
- [Four-scene reference case](four-scene-case/README.md): rainy city, sunlit alley, forest shelter, and laundry courtyard; emphasizes anchors ranging from streets and roofs to trees, structures, clotheslines, and household activity.

For every new photograph, design a new silhouette, outfit, action, and palette from its own geometry. Never trace or reconstruct a character from these outputs.
